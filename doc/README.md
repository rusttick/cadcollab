# doc/ — FreeCAD Collaboration Research

Index of this directory. Update this file whenever an entry is added,
renamed, or removed.

## possible_freecad_collaboration.md

Survey of what's live, what's dead, and where the unclaimed high-leverage
work is in the FreeCAD collaboration/PDM space.

## freecad_core_and_lens_collaboration_issues.md

Deep dive into FreeCAD's own official-channel collaboration design effort
(the #25681 issue cluster, Ondsel-Server#47/#48, the BCF plugin history,
FEP-0011 and its implementation).

## ondsel/

Ondsel-Server issue #48 ("Extent to which Lens is a PDM") and the
standards-mapping research and proposal built from it.

## optimistic_locking_research.md

Academic-literature survey on why version control for parametric CAD
remains an open research problem.

## freecad_pdm_plm_ecosystem_census.md

Catalog of every independent third-party effort, in any language, with any
interest in collaborative design in/with FreeCAD or OpenCascade.

## ecosystem/

Structured relationship graph (`graph.yaml`) built from the census, plus
the relationship-mapping and alliance/outreach analysis derived from it.

## technical_convergence_plan.md

Methodology and reading template for verifying ecosystem claims against
actual source code, repository by repository.

## architecture/

One document per repository read against the technical-convergence
template, plus source-verified corrections applied back to
`ecosystem/graph.yaml`.

## core_vs_addon_collaboration_features.md

Which collaboration mechanisms found across `architecture/` require a
FreeCAD core change versus which are addon-implementable today.

## global_boundary_crossing_research.md

CSCW/human-factors research (awareness, common ground, boundary-object
theory), PLM-adoption psychology, and the AEC/openBIM and
aerospace/LOTAR precedents for regulator-inclusive multi-org
collaboration, read against a critical assessment of what "FreeCAD as
global market leader" would actually require and whether it's realistic.
